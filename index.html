카톡 밖에서 열어 주세요

카톡 안에서는 앱을 설치할 수 없어요. 버튼을 누르면 폰 기본 브라우저로 열려요.

브라우저로 열기

    앱을 설치해 주세요

    설치하면 홈 화면에 아이콘이 생기고, 카톡 대신 앱 알림으로 받을 수 있어요.

    1. 오른쪽 위 ⋮ 를 눌러요
    2. 홈 화면에 추가 또는 앱 설치를 눌러요
    3. 홈 화면에 생긴 ONSITE 아이콘으로 열어요

    홈 화면에 추가해 주세요

    아이폰은 홈 화면에 추가한 앱으로만 알림을 받을 수 있어요. 세 번만 누르면 돼요.

    1. 화면 아래 공유 를 눌러요. 안 보이면 ⋯ 를 먼저 눌러요
    2. 목록을 올려 홈 화면에 추가를 눌러요
    3. 웹 앱으로 열기가 켜진 채로 오른쪽 위 추가를 눌러요

    추가한 뒤에는 이 창을 닫고 홈 화면의 ONSITE 아이콘으로 열어 주세요.

    아래 공유 버튼부터 눌러요 ↓

    사파리에서 열어 주세요

    아이폰에서는 사파리에서 추가해야 알림이 와요.

    복사한 주소를 사파리 주소창에 붙여 넣어 주세요.

    ✓ 설치 완료

    알림을 켜 주세요

    점검 요청 · 대책 결정 같은 할 일이 생기면 바로 알려 드려요. 위험 경고는 지금처럼 카톡으로도 와요.

    알림이 꺼져 있어요. 폰 설정 → 알림 → ONSITE에서 켠 뒤 다시 눌러 주세요.

    ✓ 알림 준비 끝

    이제 앱을 닫아도 알림이 와요

    지금 이 폰에 알림이 뜨는지 먼저 확인해 보세요.
